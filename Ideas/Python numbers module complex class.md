Standardises the operations on [[Python complex|complex numbers]].

**Fields**:
- `real`: Real component
- `imag`: Imaginary component
**Functions**:
- `conjugate()`: The complex conjugate
**Operations**:
- `complex()`: Conversion to complex
- `bool()`: Conversion to bool
- `+`, `-`, `*`, `/`, `**`, `==`, `!=`.
- `abs()`: Absolute value
