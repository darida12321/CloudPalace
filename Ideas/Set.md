A **Set** is a collection of objects, called **elements**.
If $x$ is an **element** of a set $S$, we say $x\in S$, otherwise $x\notin S$ 

We denote **finite sets** by $S=\{x_1,x_2,\dots,x_n\}$ 
We denote [[Countable infinity|countably infinite]] **sets** by $S=\{x_1,x_2,\dots\}$ 
We denote [[Uncountable infinity|uncountably infinite]] **sets** by $S=\{x|x\text{ satisfies }P\}$

Notable examples:
- [[Empty set]]: The set with no elements.
- [[Universal set]]: The set with every element.
