Most **operations** are defined by [[Python special class methods|special class methods]].

Comparison: `<`, `<=`, `==`, `!=`, `>`, `>=`, `is`, `is not`, `in`, `not in`.
Arithmetic operators: `+`, `-`, `*`, `@`, `/`, `//`, `%`, `**`, `<<`, `>>`, `&`, `^`, `|`.
Boolean operators: `not`, `and`, `or`.
Assignment: `+=`, `-=`, `*=`, `@=`, `/=`, `//=`, `%=`, `**=`, `<<=`, `>>=`, `&=`, `^=`, `|=`.
Unary arithmetic: `-`, `+`, `~`.
