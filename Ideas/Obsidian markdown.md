**Obsidian** supports the following [[Markdown]] features:
- [[Markdown headings|Headings]], [[Markdown styles|styles]], [[Markdown link|links]], [[Markdown image|images]], , [[Markdown list|lists]], [[Markdown task list|task lists]], [[Markdown horizontal rule|horizontal rule]], [[Markdown footnote|footnotes]], [[Markdown table|tables]].
- [[Markdown quote|Quotes]] and [[Obsidian callouts|Obsidian callouts]].
- [[Markdown code block|Code blocks]] with `~~~` or ```` ``` ````.
- Comments with `%%`.
- Math expression with [[LaTeX]] `$e^{2i\pi}$`  
- **Internal links**: 
	- Link to internal file: `[[File]]`, `[[File.md]]`, `[File](File)`, `[File](File.md)`.
	- Link to heading: `[[#Heading]]`, `[[File#Heading]]`, `[[File#Heading#Subheading]]`
	- Link to block: `[[File#^37066d]]`. Add `^37066d` to the end of a paragraph.
	- Change name: `[[File|Custom name]]`.
- **Embed files**:
	- Notes: `![[File]]`.
	- Image: `![[Image.jpg]]`, `![[Image.jpg|100x145]]`.
	- Audio: `![[Audio.ogg]]`.
	- PDF: `![[Document.pdf]]`, `![[Doc.pdf#page=3]]`, `![[Doc.pdf#height=400]]`.
	- Canvas: `![[Canvas.canvas]]`.
	- Search result: Use a ```` ```query ```` block with a search term.
