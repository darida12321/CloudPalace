Python has a number of built-in **constants** for convenience.

- `False`, `True`: [[Python bool|bool]].
- `None`, `NotImplemented`, `Ellipsis`: [[Python none|None]], [[Python notImplemented|NotImplemented]], [[Python ellipsis|Ellipsis]].
- `__debug__`: Set to `True` unless python was started with the `-O` option.
- **Constants** added by the [[Python site module|site module]]:
	- `quit`, `exit`: Prints “Use quit() or Ctrl-D (i.e. EOF) to exit”
	- `help`: Prints “Type help() for interactive help, or help(object) for help about object.” 
	- `copyright`, `credits`: Contain the text of copyright or credits.
	- `license`: Prints “Type license() to see the full license text”
