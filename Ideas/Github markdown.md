**Github** supports the following [[Markdown]] features:
- Basic [[Markdown styles|styles]] plus [[HTML]] for `<sub>` subscripts, `<sup>` superscripts and `<ins>` underlines.
- [[Markdown headings|Headings]], [[Markdown image|images]], [[Markdown list|lists]], [[Markdown task list|task lists]], [[Markdown quote|quotes]], [[Markdown footnote|footnotes]] and [[Markdown code block|code blocks]].
- [[Markdown link|Links]], **section links** (convert headers to lowercase, spaces to `-`) and **relative links**.
- Colour models with `#ffffff`.
- Mentions for people and teams `@github/support`.
- Referencing issues and pull requests `#my_pr`.
- Alerts based on [[Markdown quote|quote blocks]] `> [!NOTE]`.
