**Code blocks** can be created by adding 4 spaces or a tab before your text. A more commonly used version of this are [[Markdown code block|code blocks]].

```
    {
      "firstName": "John",
      "lastName": "Smith",
      "age": 25
    }
```

translates  to:

    {
      "firstName": "John",
      "lastName": "Smith",
      "age": 25
    }
