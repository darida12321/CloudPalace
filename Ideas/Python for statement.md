[[Python assignment statement|Assigns]] values in the iterable to the variable(s). It can have [[Python break statement|break]] or [[Python continue statement|continue]] statements. When the iterator is exhausted, execute the `else` block.
```python
for x in iterable:
	pass
else:
	pass
```

The `else` block doesn't activate after `break`, which can be used to simplify code in some cases.
