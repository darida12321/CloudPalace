There is only one [[Python object|object]] with the **Ellipsis** type. It's either accessed by `Ellipsis` or `...`. It generally represent omission, and used in a few cases:
- [[Python type annotation|Type annotations]]: `tuple[int, ...]` means a [[Python tuple|tuple]] of any length/
- In the body of a function instead of `pass`
- Third party libraries can use it however they see fit.
