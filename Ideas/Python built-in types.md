Python has a number of built-in types you can use. They all inherit from the base [[Python object|object]].

- [[Python object|object]]:
	- Numbers: [[Python bool|bool]], [[Python int|int]], [[Python bool|bool]], [[Python float|float]], [[Python complex|complex]].
	- Sequence types: [[Python range|range]], [[Python tuple|tuple]], [[Python string|string]], [[Python bytes|bytes]], [[Python list|list]], [[Python bytearray|bytearray]].
	- Set types: [[Python set|set]], [[Python frozenset|frozenset]].
	- Mapping types: [[Python dict|dict]].
	- Type annotation types: [[Python generic alias type|generic alias type]], [[Python union type|union type]].
	- Other built-in types:
		- One-offs: [[Python none|None]], [[Python notImplemented|NotImplemented]], [[Python ellipsis|Ellipsis]].
		- Language features: [[Python callable|callables]], [[Python class|classes]].
