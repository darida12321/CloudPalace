There are some common text styles that are widely supported.
```tx
| Markdown | Markdown | Result | 
| --- | --- | --- |
| `*Italic*` | `_Italic_` | *Italic* |
| `**Bold**` | `__Bold__` | **Bold** |
| `***Bold+Italic***` | `___Bold+Italic___` | ***Bold+Italic*** |
| `` `Code` `` | ` ``Code`` `| `Code` |
```

There are some more styles available, but they are not always supported.
```tx
| Markdown | Result | 
| --- | --- |
| `~~strikethrough~~` | ~~strikethrough~~ |
| `==highlight==` | ==highlight== |
| :joy: | 😂 |
| ~subscript~   | <sub>subscript</sub>   |
| ^superscript^ | <sup>superscript</sup> |
```
