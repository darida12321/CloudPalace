This module gives a hierarchy of base classes for numbers.

These are all of the **numeric** values. The `__repr__()` and `__str__()` display them as numbers. There are three sub-categories:


- **Number**: Nothing defined, useful to check if a variable is a number.
	- **[[Python numbers module complex class|Complex]]**: Standardises the operations that [[Python complex|complex]] numbers define.
		- **[[Python numbers module real class|Real]]**: Standardises the operations that [[Python float|floats]] define.
			- **[[Python numbers module integral class|Integral]]**: Standardises the operations that [[Python int|ints]] and [[Python bool|bools]] define.
