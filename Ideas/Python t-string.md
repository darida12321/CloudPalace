A **formatted string literal** is created similarly to regular [[Python t-string|t-strings]], but with an `t` or `T` at the beginning (`t'string'`, `t"string"`, `t'''string'''`, `t"""string"""`).

**F-strings** can execute arbitrary code in their body which makes them unsafe in some cases.
**T-strings** are templates, where you have full control about how the content gets processed.
