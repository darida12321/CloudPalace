There are 6 levels of headings, although some programs don't implement all of them.
```tx
| Markdown | Alternative | Result | 
| --- | --- | --- |
| `# Heading 1` | <code>Heading 1<br>=========</code> | # Heading 1 |
| `## Heading 2` | <code>Heading 2<br>---------</code> | ## Heading 2 |
| `### Heading 3` | | ### Heading 3 |
| `#### Heading 4` | | #### Heading 4 |
| `##### Heading 5` | | ##### Heading 5 |
| `###### Heading 6` | | ###### Heading 6 |
| `Paragraph` | | Paragraph |
```
