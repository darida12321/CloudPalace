**Discord** supports the following [[Markdown]] features:
- Basic [[Markdown styles|styles]] plus `__underline__` and `||spoilers||`.
- The first three [[Markdown headings|headings]], plus subtext `-# subtext`.
- [[Markdown link|Links]], [[Markdown list|lists]] and [[Markdown quote|quotes]], plus `>>>` for multiline quotes.
- [[Markdown code block|Code blocks]] with syntax highlighting for many languages.
