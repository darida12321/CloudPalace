Inherits from **[[Python numbers module real class|numbers module real class]]**. A [[Floating-point representation|double precision float]] in python.

**Constructor**:
- `1.2`
- `float(1)`
- `float('-4.5j+2')`
**Class methods**:
- `float.from_number()`: Return a float from a [[Python numbers module|number]].
- `float.fromhex()`: Return float from [[Hexadecimal|hexadecimal]] string. (e.g. `"0xa3b4.e5p10"`)
**Functions**:
- `x.as_integer_ratio()`: Return pair of ints whose ratio is x.
- `x.is_integer()`: True if it has an integral value.
- `x.hex()`: Convert x to a hexadecimal string. 
**Operations**:
- `complex()`: Conversion to complex
- `bool()`: Conversion to bool
- `+`, `-`, `*`, `/`, `**`
- `abs()`: Absolute value
