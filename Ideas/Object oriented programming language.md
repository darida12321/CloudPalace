**Object oriented programming (OOP)**: is a design philosophy that organizes code around "objects". There are four foundational principles:
- **Encapsulation**: Data belonging to one object should be bundled together.
- **Abstraction**: Objects should hide their complex behaviour, and provide interfaces.
- **Inheritance**: A class should be able to adopt and modify the behaviours of another.
- **Polymorphism**: Objects should respond to the same method call in different ways.
