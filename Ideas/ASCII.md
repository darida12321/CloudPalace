A way of representing text in [[Binary|binary]]. **ASCII** (American Standard Code for Information Interchange) was one of the first representations developed. It used **7 bits** per character to encode 127 symbols:
- **0-31**: Control characters (based around the typewriter). e.g.: backspace, new line.
- **32-127**: Printable characters. e.g.: `32:' '`, `40:'('`, `65:'A'`, `97:'a'`.
- A full list is available [here](https://www.ascii-code.com/).

They used 7 bits because **ASCII** was made when connections were slow, so that extra bit mattered, and the medium was noisy, so the 8th bit was used as a [[Parity bit|parity bit]]
